# 🎵 YouTube to MP3 Converter

A simple, clean desktop app that converts videos from YouTube, SoundCloud, TikTok, Instagram, and many more platforms to high-quality MP3 files.

![Platform](https://img.shields.io/badge/Platform-Windows-lightgrey?style=flat-square&logo=windows)
![Free](https://img.shields.io/badge/Free-Personal%20Use-green?style=flat-square)

---

## ✨ Features

- 🔗 Supports **YouTube, SoundCloud, TikTok, Instagram, Vimeo**, and [many more](https://github.com/yt-dlp/yt-dlp/blob/master/supportedsites.md)
- 🎧 High-quality MP3 output — **320 kbps, 48 kHz**
- 🖼️ Auto-embeds **thumbnail cover art** and **metadata**
- 📁 Choose your own output directory
- 📊 Live progress bar and real-time conversion log
- 🔄 Reset button to quickly start a new conversion
- 🪟 Standalone `.exe` — no installation or Java required

---

## 📦 Download

1. Go to the [**Releases**](../../releases) page
2. Download the latest `Mp3Converter.exe`
3. Run it — that's it!

> ⚠️ **Windows only.** `yt-dlp` and `ffmpeg` are bundled inside — no extra setup required.

---

## 🛠️ How It Works

The app uses **[yt-dlp](https://github.com/yt-dlp/yt-dlp)** to fetch the audio stream and **[FFmpeg](https://ffmpeg.org/)** to encode it to MP3.

| Setting | Value |
|---|---|
| Format | MP3 |
| Bitrate | 320 kbps |
| Sample Rate | 48,000 Hz |
| Metadata | ✅ Embedded |
| Cover Art | ✅ Embedded |
